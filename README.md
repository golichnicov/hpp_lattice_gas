\# Моделирование решёточного газа HPP (D2Q4)



Реализация двумерного клеточного автомата решёточного газа HPP (Hardy–Pomeau–Pazzis)



\## Архитектура и особенности реализации

\* \*\*Ядро (`model.py`)\*\*: векторизовано средствами библиотеки NumPy без использования медленных вложенных циклов.

\* \*\*Интерфейс (`cli.py`)\*\*: CLI-приложение на библиотеке `click`.

\* \*\*Тесты (`test\_hpp.py`)\*\*: покрытие модульными тестами на `pytest` (правила столкновений, законы сохранения массы и импульса, обратимость во времени).
